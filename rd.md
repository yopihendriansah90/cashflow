# Rancangan teknis
Laravel 13, PHP 8.5, Blade, TailAdmin, Tailwind 4, Alpine 3, Vite 7, Node 22, Pest 4. Produksi satu instance Laravel, MySQL dan SMTP; SQLite untuk uji lokal. Gunakan sesi dan password broker Laravel. Gunakan middleware/policy, selalu verifikasi keanggotaan aktif pada setiap permintaan. Sistem admin tidak memberi akses ke data rumah tangga lain. Kode pasangan acak berentropi tinggi, disimpan sebagai hash, berlaku 24 jam, rate limited, kode lama dicabut saat penggantian. Gunakan transaksi dan batasan unik untuk serialisasi penukaran dan pencabutan. Jangan log kode.
## Tahapan dan verifikasi
1. Akun dan isolasi: pendaftaran, login/logout, reset, onboarding, kode, keluar/cabut, proteksi ruang serta pengujian. Uji akses lintas ruang, sesi aktif pascapencabutan, batas keanggotaan, kode kedaluwarsa, dicabut, dipakai ulang dan penukaran bersamaan di MySQL khusus tes. SMTP produksi dikonfigurasi terpisah; tes notifikasi boleh memakai fake.
2. Dompet, kategori, transaksi, dan audit. Simpan perubahan dan revisi secara atomik. Tolak transaksi sebelum tanggal mulai wallet, perpindahan lintas ruang, dan biaya negatif. Koreksi saldo awal memperbarui saldo historis tanpa mengubah arus. Uji top-up Rp200.000 + Rp2.500.
3. Laporan dan CSV. Saldo akhir = saldo awal + dampak transaksi aktif hingga akhir bulan. Hilangkan dompet yang belum mulai. Arus bulan hanya transaksi bulan itu. Gunakan satu perhitungan untuk laporan/ekspor. Uji formula CSV, arsip dan perubahan historis.
4. Identitas dan UI. Logo PNG/WebP, favicon PNG, maksimal 1 MB per file, validasi isi, buat nama file server. Simpan file baru sebelum mengganti referensi dan pertahankan aset lama bila transaksi gagal. Uji otorisasi dan fallback, browser seluler dan interaksi dialog.
Jalankan composer test, php artisan route:list dan npm.cmd run build pada Windows. Gunakan database pengujian terpisah dan laporkan verifikasi MySQL yang belum bisa dijalankan.
